Privacy Policy

ifmade · effective November 6, 2026

ifmade is an engine operated by Chris Marriott that makes videos and publishes them to YouTube channels he owns or manages. This page describes what it accesses and what happens to that data.

YouTube API Services

ifmade uses YouTube API Services. Their use is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What the engine accesses

Through Google's YouTube Data API and YouTube Analytics API, the engine uploads videos to the connected channels and sets their titles, descriptions, tags and thumbnails; sets the channels' details, banners and watermarks; posts comments from the channel's own account; reads the connected channel's identity to confirm it is the right channel; and reads views, watch time and related analytics for the connected channels.

Whose data

Only the operator's own channels are connected. The engine is used by one person and is not offered to the public. No one else's Google account is ever connected to it.

Where data is stored

Authorization tokens are kept in the keychain of a computer the operator runs. Read-only sign-ins that measure the channels' videos are kept as an encrypted secret on the operator's Cloudflare account. Analytics the engine downloads are kept in the operator's private files, private code repository and a private Cloudflare database, and the videos it makes in the operator's own cloud storage. Neither these pages nor the short links set cookies.

Short links

Videos may show short links on ifmade.link. When a viewer opens one, the operator's link service records the time, the link, the country, the device type, the referring site's host name, the browser's user-agent string and the name and number of the network it came from, then forwards the viewer. These tell people from automated link checkers. It does not keep IP addresses, and it cannot tell who a visitor is.

Sharing

Data is not sold, shared or transferred to anyone. The engine has no advertising partners.

Google API Services User Data Policy

The engine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google's security settings page, or by deleting the token from the operator's keychain.

Deleting data

To ask for stored data to be deleted, write to the contact below. It is deleted as soon as possible and within 7 days. Deleting data here does not change what YouTube itself stores.
