Privacy Policy

Channel Tools · effective September 30, 2026

Channel Tools is a set of command-line scripts operated by Chris Marriott to read analytics and update video metadata on YouTube channels he owns or manages. This page describes what the tools access and what happens to that data.

What the tools access

Through Google's YouTube Data API and YouTube Analytics API, the tools read view counts, watch time and related analytics for the connected channels, read the title, description and tags of videos on those channels, and, when the operator runs a command that asks for it, update the title, description and tags of the operator's own videos or post a comment from the operator's own account.

Whose data

Only the operator's own channels are connected. The tools are used by one person and are not offered to the public. No one else's Google account is ever connected to them.

Where data is stored

Authorization tokens and any data the tools download are stored on the operator's own computer, in files readable only by the operator's user account. Nothing is sent to any server other than Google's APIs. There is no database, no hosting, no analytics and no third-party service.

Sharing

Data is not sold, shared or transferred to anyone. The tools have no advertising and no partners.

Google API Services User Data Policy

The tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account's third-party access page, or by deleting the token file on the operator's computer.

Changes

If this policy changes, the new text will appear on this page with a new effective date.
